# Derin araştırma klasörü

1. `PROMPT-1-teknoloji-hiz-yol-haritasi.md` → bir araca ver (ChatGPT Deep Research önerilir).
2. `PROMPT-2-pazar-ve-pitch.md` → başka bir araca ver (Gemini Deep Research önerilir).
3. Sonuçları `SONUC-1-<arac>.md`, `SONUC-2-<arac>.md` olarak buraya kaydet (araç adı + tarih başa).
4. Sonuçlardan çıkan kararlar `docs/DECISIONS.md`'ye satır olarak girer; teknoloji değişikliği AGENTS.md §3'e ancak ekip onayıyla yansır.

Kural: araştırma sonucu ne derse desin, Geliştirme Günü kapsamı (AGENTS.md §2) büyümez; yeni fikirler yol haritası slaydına gider.
